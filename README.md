# Maze Snake Game

## Description
Maze Snake Game is a c++-based game where the player controls a snake through a maze while avoiding collisions and attempting to achieve the highest possible score.

## Features
- Snake movement controls
- Maze-based gameplay
- Collision detection
- Score tracking
- Simple graphical user interface

## How to Run
1. Download or clone the repository.
2. Open the project in your IDE.
3. Run the main file.
